## Overview

This repository contains all lab-related work for the 4th semester, organized subject-wise along with supporting theoretical materials and mini project resources.

---

## Directory Structure

```
4-th sem labs/
│
├── algo/                  # Algorithms Lab (Assignments & Reports)
│
├── paradigm/              # Programming Paradigm Lab (Assignments)
│
├── others/                # Supporting Materials (Non-Lab Content)
│   ├── algo_notes         # Algorithm theory notes
│   ├── coa_notes          # Computer Organization & Architecture notes
│   ├── ds_notes           # Data Science notes
│   └── mini_project/      # Mini project files and report
│
```

---

## Description

### algo/
Contains assignments and reports related to the Algorithms Lab.

### paradigm/
Contains assignments for the Programming Paradigm Lab.

### others/
This directory is not intended for lab submissions. It includes:

- Theory notes for core subjects:
  - Algorithms
  - Data Science
  - Computer Organization & Architecture

- Mini project materials:
  - Implementation files
  - Supporting resources
  - Final report

---

## Usage

- Use `algo/` and `paradigm/` for lab assignments
- Use `others/` for notes and project-related content
